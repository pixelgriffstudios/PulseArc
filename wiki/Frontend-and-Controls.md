# Frontend and Controls

## Standard controller layout

PulseArc uses an Xbox-style layout by default:

- **D-pad / left stick:** navigate
- **A / South:** accept, play, or pause
- **B / East:** go back
- **LB / RB:** change page, tab, chapter, or track where shown
- **View + Menu (hold):** exit the active game and return to PulseArc
- **View + A / South:** open the emulator menu when supported
- **View + RB:** save state when supported
- **View + LB:** load state when supported

Keyboard Escape remains an exit fallback in supported games and apps. Some native applications have their own close confirmation.

## Inserted media

When exactly one supported game is detected, **Play** launches it directly. When several games are present, Play opens a browser that shows system, title, artwork, and runtime. Use the on-screen button legend because install and paging controls can vary by screen.

## Display and audio

Settings includes automatic output plus common 1080p and 720p modes. Emulator internal resolution can be adjusted for supported systems. If a game is slow, lower its internal resolution before changing the TV output.

Audio can be set to automatic, HDMI/DisplayPort, or analog. If audio returns to an internal speaker after changing hardware or profiles, select the desired output again and test it before launching a game.

## Soft restart versus PC restart

- **Restart frontend** reloads only PulseArc's interface and is useful after media or theme changes.
- **Restart PC** performs a full operating-system reboot.
- **Shut down** powers off the computer.

Do not remove a drive while a copy, install, recording, save, or update operation is in progress.
