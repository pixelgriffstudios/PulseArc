# Library, Saves, Cheats, and Profiles

## Internal Library

Games installed from external media appear in Library and are grouped by system. The Library is intended for installed local content; inserted games remain under Play. Artwork is downloaded when enabled and cached locally. Put `cover.png` beside a Windows game for a dependable manual cover.

Game management actions can include Play, Move, Copy, or Delete depending on the item and available storage. Confirm the exact destination before copying to removable media. Deleting a game does not automatically authorize deletion of its saves; manage those separately from Saves.

## 3D Plaza

3D Plaza presents installed games and configured media in a navigable 3D environment. The normal Library remains available as the faster list/gallery view. Settings can choose Home or 3D Plaza as the startup screen.

## Profiles

PulseArc keeps the Default profile and supports up to three additional profiles, for four total. Games are shared, while saves, memory cards, controller layouts, cheats, and user settings remain profile-specific.

Use **Extras > Profiles** to:

- select a profile with A/South;
- create a new profile when a slot is available;
- rename it with the on-screen control;
- cycle available avatars with LB/RB;
- delete an extra profile with X/West and confirmation.

The Default profile cannot be removed.

## Saves

Saves lists data by game and system rather than exposing emulator directory names. Use it to inspect, copy, back up, restore, or delete supported save data. Save-state hotkeys are **View + RB** to save and **View + LB** to load when the emulator supports them.

Do not copy live save data while a game is running. Close the game first. A save state is emulator/version-specific and is not a substitute for the game's normal memory-card or battery save.

## Cheats

Cheats are opt-in and appear only when a supported database and matching game identity are available. A displayed cheat does not guarantee compatibility with every revision or region. Enable one change at a time, then launch the game and verify it.

Use **View + A/South** to open the emulator menu where supported. RetroArch and standalone emulators can have different cheat formats. A code for a USA revision may not work on a World, Europe, Japan, or different-revision ROM.

Back up important saves before using cheats. Disable a failing cheat rather than repeatedly forcing it against a mismatched game.
