# PulseArc OS User Guide

PulseArc is a controller-first Linux gaming and media system. It launches games from internal storage, USB drives, SD cards, CDs, and DVDs. Loose ROMs normally need no configuration. Portable Windows games can remain ordinary folders with a small optional `pulsearc.toml` manifest.

> PulseArc is beta software. Install it on spare hardware, back up important disks, and carefully verify the selected destination before erasing a drive.

## Main screens

- **Play** shows media currently inserted. One detected game launches directly; multiple games open a controller-friendly browser.
- **Library** contains games installed on internal storage, grouped by system.
- **3D Plaza** provides a navigable 3D library and media environment.
- **Music** plays local music, audio CDs, and configured radio streams, with optional projectM visuals.
- **TV** provides free live-TV sources, user-added IPTV playlists, and DVR recordings.
- **Apps** launches Steam, Heroic, cloud-gaming services, the web browser, and archive/media import.
- **Saves** manages profile-specific save data and backups.
- **Cheats** manages opt-in cheats supported by the selected emulator.
- **Controllers** tests and configures controllers and per-game mappings.
- **Settings** controls display, audio, volume, artwork, startup screen, runtimes, and personalization.
- **Extras** contains BIOS Manager, profiles, themes, screensavers, controller tools, updates, recording, Bluetooth, and Wi-Fi.
- **Power** offers frontend restart, PC restart, and shutdown.

## Legal and safety note

Use only games, firmware, keys, media, and online services you are authorized to use. PulseArc does not include copyrighted console BIOS files, encryption keys, commercial games, or private service credentials.
